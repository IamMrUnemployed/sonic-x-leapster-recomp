# Sonic X (Leapster) | RecompStore Edition

An unofficial, free Windows x64 fan port by MrUnemployed. It uses statically recompiled ARCompact code and runs without a separate emulator.

This edition requires the original game files from your own compatible copy.

## Setup

1. Extract the Windows ZIP to a folder.
2. Place your USA cartridge dump beside SonicX.exe and name it `Sonic X (USA).bin`.
3. Create a `data` folder next to SonicX.exe. Put the matching Leapster firmware at `data/bios.bin` and the matching calibration EEPROM image at `data/nvram.bin`.
4. Run `SonicX.exe`.
